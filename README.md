# AfriBaobab

AfriBaobab est la base souveraine du projet AfriChain.

Ce dépôt est personnel, autonome et entièrement contrôlé par son propriétaire.
Le but est de construire une architecture africaine, modulaire, sécurisée et évolutive.

## Structure
- afri-core : coeur blockchain, types, crypto, transactions
- afri-store : stockage et persistence
- afri-net : réseau et peer discovery
- afri-api : couche d’accès
- afri-node : moteur d’exécution
- afri-apps : services continentaux

## Souveraineté
Le code, les règles, les clés et les décisions restent sous le contrôle du propriétaire.

## Démarrage
```bash
cargo build
cargo run -p afri-node
```
