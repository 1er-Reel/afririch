## 💚 C'est quoi, AfriChain ?

<br />

AfriChain est une blockchain **100% africaine**, construite **from scratch** en Rust.

Ce n'est **pas** un token sur la blockchain de quelqu'un d'autre.
Ce n'est **pas** un fork de Bitcoin ou d'Ethereum.
**C'est la nôtre.**

AfriChain est la **Banque Numérique de l'AES** (Alliance des États du Sahel 🇲🇱🇳🇪🇧🇫).
L'utilisateur voit une banque simple, comme Orange Money.
La blockchain travaille en silence, derrière.

<br />

> *« L'Afrique est le continent le plus riche.
> Il est temps que sa technologie le reflète. »*
