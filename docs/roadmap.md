# AfriChain Roadmap

This roadmap focuses on making the project executable, credible, and maintainable.

## Phase 1 — Foundation

- clean repository structure
- define core modules
- separate blockchain engine from ecosystem tools
- write a minimal but accurate README
- establish a buildable Rust prototype

## Phase 2 — Blockchain prototype

- define `Block` and `Transaction`
- add wallet abstraction
- implement basic validation
- persist chain to disk
- add tests for block integrity and transaction handling

## Phase 3 — Local network

- peer discovery
- transaction relay
- block propagation
- local network simulations
- chain synchronization checks

## Phase 4 — API and dashboard

- JSON or HTTP endpoints
- wallet status
- account balance
- chain metadata
- transaction history
- health checks

## Phase 5 — Security and resilience

- verification rules
- ledger integrity checks
- crash recovery
- node restart behavior
- unit and integration tests

## Phase 6 — Ecosystem modules

- mesh networking experiments
- educational security tools
- regional services prototypes
- documentation and demos

## Phase 7 — Public demonstration

- stable local demo
- showcase wallet and blockchain flow
- document installation and usage
- prepare a user-facing presentation

## Success criteria

A meaningful project milestone is reached when the repository can:

- build successfully
- create a wallet
- create transactions
- mine or validate blocks
- restore state from disk
- expose a minimal API

This is the minimum required level of seriousness for a blockchain initiative.
